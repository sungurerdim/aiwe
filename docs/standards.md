# Standards registry

The one registry of aiwe's rules (#314 K41): every design rule DR-1…DR-23 and every standard of
SPEC §3.1. SPEC §3 is generated from the rows below; a difference between the two is a `repo/rules`
finding (the comparison check is planned, #314 K41).

A row: **id** · **statement** (the text SPEC carries) · **enforcement** (a check id, a test path
relative to `internal/`, or `judgement:<role>`; `planned:` marks the enforcement a row does not have
yet) · **fix** (the one line an agent reads when the row is red) · **milestone** (the roadmap goal of
§13 whose conformance unit this row parents, #314 K36) · **rev** (the short hash of the row's
statement and enforcement, the first 8 hex of sha256(statement + LF + enforcement); every row below
carries it).
